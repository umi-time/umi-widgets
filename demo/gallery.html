Umi Widgets Gallery

A visual showcase of the reusable widgets included in the Umi-Time component library. This page serves as a development sandbox and manual integration test environment.

<umi-time>

Produces canonical Umi-Time specification strings suitable for machine processing, serialization, and precise display.

<umi-display>

Human-friendly Umi-Time readouts for user interfaces.

<umi-clock>

A location-aware Umi-Time clock showing local solar context, daylight, twilight, and Umi progression throughout the day.

<umi-time-explorer>

Interactive controls for exploring different dates and Umi offsets.

<umi-timeline>

Visualizes a single shared Umi-Time moment across multiple geographic locations and solar conditions.

<umi-world-map>

Interactive world map featuring daylight regions, latitude and longitude grids, pinned clocks, cursor clocks, and timezone overlays.

<umi-tip-rotator>

Displays rotating educational tips and onboarding content.

<umi-options-menu>

Persistent toggle menu for enabling and disabling application features.
